# pcl-guard

纯净的 Plain Craft Launcher 2 (PCL2) 运行环境守护与版本回退工具。

本项目专用于固化离线防更新配置、比对可执行文件哈希并在被更新或篡改时自动安全回退，不负责启动游戏本体。

---

## 核心机制

1. **固化离线防更配置**  
   启动时自动检索并修正 `PCL\Setup.ini`，确保包含 `SystemSystemUpdate:3`。逆向证实该参数对应彻底关闭更新提示与后台下载逻辑。若缺少该项则自动追加，已有其他配置项原样保留。

2. **基准哈希校验**  
   比对当前目录 `Plain Craft Launcher.exe` 的 SHA256 哈希值：  
   - 基准版本：2.13.1.1  
   - 基准 SHA256：`30EB93C62FC51EDE0898648E67455478A3D5A4F279938AE65AEC77B84CB9703F`

3. **运行进程检测与确认关闭**  
   运行前自动检索正在运行的相关程序：  
   - 当前目录下运行中的 `Plain Craft Launcher.exe` 主进程  
   - 由 PCL2 启动的子进程（如 Minecraft 游戏核心 `javaw.exe` / `java.exe`）  
   - 即使 PCL2 已在启动游戏后退出，依然能通过命令行目录关联识别出当前整合包正在运行的 Java 游戏进程  
   若发现相关进程，**主动弹出模态确认对话框**，列出进程名与 PID 并询问是否关闭：  
   - 选择【是】：先发送窗口退出信号，超时后安全终止，解除可执行文件与目录锁，顺利执行后续检查与回退。  
   - 选择【否】：保留程序运行，绝不强行误杀。

4. **覆盖前自动归档备份**  
   若主程序缺失，直接从内嵌母本释放。若主程序哈希与基准不符，在执行覆盖修复前，自动将现有旧程序复制备份至两处：  
   - `PCL\Backup\Plain Craft Launcher_{时间戳}.exe.bak`（保留历史记录）  
   - `Plain Craft Launcher.exe.bak`（快捷备份）

5. **单文件无损自愈**  
   程序内嵌了 5.75MB 的 2.13.1.1 黄金母本二进制。释放与替换过程中仅覆盖主程序本身，不影响任何游戏存档、MOD 或配置，且保持标准的普通文件属性（不施加只读限制）。

6. **纯守护不启动游戏**  
   校验与修复完毕后直接退出，绝不擅自拉起 PCL2 进程。

## 下载与使用

### 下载预编译文件
在项目的 [Releases](../../releases) 页面可以直接下载最新打包好的独立可执行文件：
- `pcl-guard.exe`：单文件独立程序
- `sha256.txt`：官方编译产物哈希校验文件

### 日常运行
将 `pcl-guard.exe` 放入 PCL2 主程序所在根目录，双击运行：
- 若版本完好，弹出轻量提示框确认状态后退出。
- 若版本异常，完成备份并自动回退后弹出恢复提示框。

### 脚本与静默模式
在自动化脚本或批处理中传入静默参数，程序将在后台静默执行检查与自愈，不弹出任何窗口：

```cmd
pcl-guard.exe /silent
```

也可以使用 `-s`、`--silent` 或 `-q`。

## CI/CD 自动化构建

项目配置了完整的 GitHub Actions 工作流（`.github/workflows/release.yml`）：
- **自动测试构建**：每次向主分支提交代码或提交 PR 时，自动在 Windows 环境下编译并生成测试构建工件。
- **Tag 自动化发版**：向仓库推送以 `v` 开头的版本标签（如 `v1.0.0`）时，GitHub Actions 会自动触发构建、计算 SHA256 校验和、创建 GitHub Release 并上传发布产物。

## 本地编译

项目采用 Windows 原生自带的 C# 编译器，无需安装额外 SDK 或第三方库。

### 目录结构
```text
pcl-guard/
├── .github/
│   └── workflows/
│       └── release.yml     # GitHub Actions 自动化工作流
├── build.bat               # 双击一键编译脚本
├── build.ps1               # PowerShell 编译脚本
├── src/
│   ├── Program.cs          # 纯守护校验与自愈逻辑
│   ├── PCL_Icon.ico        # PCL 原始高清图标
│   └── Plain Craft Launcher.exe  # 2.13.1.1 基准母本二进制
├── bin/
│   ├── pcl-guard.exe       # 编译生成的独立单文件
│   └── sha256.txt          # 校验和文件
└── README.md
```

### 手动构建
双击运行 `build.bat`，或在命令行运行：

```cmd
build.bat
```

编译脚本会自动定位 Windows 系统自带的 `csc.exe`，将基准二进制作为内嵌资源编译打包为单个独立的 GUI 程序。
